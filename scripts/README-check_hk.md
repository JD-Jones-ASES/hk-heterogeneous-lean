# check_hk.py — what it certifies

`python scripts/check_hk.py` (standard library, Python >= 3.9, one process, under a second; `--T=200` replays longer, `--explore` prints report-only slack tables) replays Mirtabatabaei–Bullo's (2.1) with `<=` for the eight systems of this repository: the six of Hegarty–Ognissanti–Wedin (arXiv:2610.03229v1, §2–§5) and the two smaller constant-digraph systems of `Challenge.lean` (five SBC agents over Q(√2), six SBI agents over Q(√249)). Arithmetic is exact in Q(√d) (pairs of Fractions, exact sign tests); no floats in any check, no asserts.
It certifies for t < T: each closed form, each full neighbourhood table (0-indexed, per parity) as pinned in `Challenge.lean`, no boundary tie for any pair and R in {r_i, r_j}, the arc lists of the paper's §4 and §5 and Claim 1 of both spectator systems, the spectators strictly on one side for t >= 1.
It certifies for all t the inductive step: with u = λ^t (and w = 5^-t or 4^-t) as atoms, every membership inequality has a constant strict sign on the parity boxes (exact corner test), the update identities (row means of x_∞ and of each offset vector) hold exactly, and u ↦ λu carries each parity box into the other.
It computes the equi-topology distances (Def 4.1) at six limits against the pinned zero sets, and the per-step factors (Def 6.1) of the four constant-digraph systems for t = 0..5, with fvct(x(t)) = x_∞ certified by A(x(t)) x_∞ = x_∞ and A(x(t)) v = λv, |λ| < 1.
Nine forged controls (perturbed or conjugated initial data, swapped parity tables on the replay and on both boxes, a changed radius, a boundary tie, a wrong or conjugated rate) must each be rejected; the last line is `VERDICT: PASS` only if the genuine data pass and every control fails.
It does NOT certify: anything in Lean (the Lean proofs are the formal content; this is an independent replay of the same data); definitions beyond (2.1), (2.2), Def 4.1 and Def 6.1 as coded here; Theorem 6.4(iii); genericity; the spectator systems' statements beyond the claims listed above.
Setting the environment variable `HK_KILL` to a file path stops every loop once that file exists; unset, nothing is consulted.
